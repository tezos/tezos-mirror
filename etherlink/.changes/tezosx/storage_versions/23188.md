  timestamp from `/evm/world_state/fees/` to `/common_world_state/fees/`
  (`backlog` and `last_timestamp`). The kernel keeps them in the
  `/common_world_state` keyspace, under the block mirror, so a reverted block
  leaves them unchanged. The fee configuration stays in
  `/evm/world_state/fees/`.
