- The storage version is now 72. It carries no data migration: the version is
  the signal on which the node selects where it reads the `debug_trace*`
  output (`/common_world_state/trace/`) and the per-transaction `http_trace*`
  output (`/common_world_state/__http_trace/traces/`). The kernel writes both
  in the `/common_world_state` keyspace instead of `/evm/world_state`. The
  tracer input `/base/trace/input` and the flag `/base/__http_trace_enabled`
  do not move.
