- A failed kernel upgrade logs which preimage or storage key failed and
  whether the previous kernel is restored, in place of a fixed message.
- A failed storage migration logs its error before the kernel falls back to
  the previous kernel.
- The kernel upgrade no longer writes the new kernel to
  `/__sdk/installer/reveal` before it moves it to `/kernel/boot.wasm`.
- The kernel backup and its restore no longer load the whole kernel in memory.
