- Read the gas backlog, which feeds `eth_gasPrice`, from
  `/common_world_state/fees/backlog` on kernels at storage version 73 or
  higher, and from the previous path otherwise. Operators must upgrade to this
  release before running a V73+ kernel: an older node finds no backlog there
  and answers with the minimum gas price. The release stays
  backward-compatible with pre-V73 kernels.
