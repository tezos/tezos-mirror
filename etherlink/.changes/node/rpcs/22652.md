- Added the `run_script_view` RPC
  (`POST /tezlink/chains/main/blocks/<block>/helpers/scripts/run_script_view`),
  a port of the L1 helper: it simulates a call to a Michelson view and
  returns the value it produces, normalized with the requested
  `unparsing_mode`, so `octez-client run view <view> on contract <KT1>`
  now works against the Michelson runtime. For an ordinary view the
  execution context and error kinds match L1, with four differences: a
  failing view reports the rejection value as text rather than as L1's
  structured `script_rejected`; `other_contracts` and `extra_big_maps`
  are rejected rather than ignored; the gas budget is capped at this
  runtime's `hard_gas_limit_per_operation` (660,000 gas), so
  `unlimited_gas` raises nothing and a larger explicit `gas` is clamped;
  and `now` must be a non-negative timestamp (`gas` / `now` / `level` are
  rejected outside non-negative int64 / int64 / u32).
