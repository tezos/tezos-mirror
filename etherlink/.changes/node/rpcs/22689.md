- `run_script_view`'s `source` field is now honoured for the enshrined
  gateway's `staticcall_evm` view, which reaches the EVM as its
  `msg.sender`. Before, every such call reported the gateway as its own
  caller. Ordinary views are unchanged (`source` stays inert, as on L1),
  and an implicit `source` on an enshrined target is rejected: only an
  originated contract can execute `VIEW`.
